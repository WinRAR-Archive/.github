# WinRAR Archive - Archive, Extract, Test, and Split Volumes

## About WinRAR

WinRAR reads and writes archives. A WinRAR archive is the container. WinRAR extract writes members out. WinRAR test checks readability. WinRAR split cuts a large container into volumes. WinRAR zip is the zip format when you need interchange, not only rar.

Create a WinRAR archive from a named folder, or WinRAR extract into a new folder, never blindly over the source. Run WinRAR test after a copy across disks. Use WinRAR split when a volume size is required. Use WinRAR zip when the other side asked for zip.

WinRAR is an archiver. A WinRAR archive, WinRAR extract, WinRAR test, WinRAR split, and WinRAR zip exist to pack, unpack, and verify, on files you may handle.

## Overview

![WinRAR](https://www.win-rar.com/fileadmin/images/products/winrar-start.png)

WinRAR is a list of members plus a write. A WinRAR archive is that list. WinRAR extract is the write out. WinRAR test is a read-through. WinRAR split is size policy. WinRAR zip is format policy.

Never extract onto the only copy. Never delete sources on a failed WinRAR test. Paths inside the archive should be relative and boring. If you set a password, treat it as a secret. Solid archives change how a single member extract costs; know that before you pack logs.

## Key Features of WinRAR

- **Archive as a container** – A WinRAR archive should be named after the set and the date. Open it. Read paths. WinRAR extract to a new folder. WinRAR test after a copy. WinRAR split only if required. WinRAR zip if the receiver cannot read rar.
- **Extract as a new tree** – WinRAR extract into an empty destination. Overwrite policy explicit. A WinRAR archive with absolute paths is a warning. WinRAR test first if the file came off untrusted media. WinRAR split volumes must all be present. WinRAR zip extracts the same way.
- **Test as a read-through** – WinRAR test before you throw away sources, and after a copy. A failed test means keep the originals. Do not WinRAR extract a bad archive as if it were complete. WinRAR split sets fail if a volume is missing. WinRAR zip test is the same idea.
- **Split as volume size** – WinRAR split when a path or a medium has a size cap. Keep all volumes together. A WinRAR archive set without part N will fail WinRAR test. WinRAR extract needs the set. WinRAR zip can also split if you chose zip; do not mix schemes.
- **Zip as interchange** – WinRAR zip when the other tool expects zip. Do not assume rar everywhere. A WinRAR archive in zip format still gets WinRAR extract and WinRAR test. WinRAR split still applies if you set volumes.

## Quick Start with WinRAR

1. **Pack or open** – To pack: select a folder, create a WinRAR archive with a dated name. To unpack: open the WinRAR archive. Do not WinRAR extract yet. Run WinRAR test. Note whether WinRAR split parts are complete. Note whether you need WinRAR zip for the other side next time.
2. **Extract to a new folder** – WinRAR extract into empty space. Confirm paths. Do not overwrite the source tree. If WinRAR test failed, stop. If a WinRAR split volume is missing, stop. WinRAR zip members unpack the same way.
3. **Verify the output** – Open a known file from the destination. If you still have sources, keep them until WinRAR test on a recopied archive also passes. A WinRAR archive that travelled should be tested again. WinRAR extract of a subset is fine. WinRAR split sets should stay together.
4. **Optional split** – If a cap exists, rebuild with WinRAR split. WinRAR test the set. Store all parts. Prefer WinRAR zip only if the receiver needs zip volumes.
5. **Stop** – Delete sources only after WinRAR test and a spot check. Do not leave a half WinRAR extract. Name the WinRAR archive so the next person knows the set.

## Who Will Like WinRAR

- **Operators** – Log packs. A WinRAR archive, WinRAR test, WinRAR extract to a staging folder. WinRAR split if a path is capped. WinRAR zip if the other team asked.
- **Admins** – Config bundles. Dated WinRAR archive, WinRAR test after copy, WinRAR extract on the target into a new folder. Avoid WinRAR split unless policy requires. WinRAR zip for interchange.
- **Developers** – Source zips when zip is required: WinRAR zip, WinRAR test, WinRAR extract. A WinRAR archive in rar only inside your own pipeline. WinRAR split rarely.
- **Technicians** – Media drop. WinRAR test first, WinRAR extract to a holding disk, keep the WinRAR archive. WinRAR split sets copied as a whole. WinRAR zip if that is what arrived.
- **Archivists** – Intake containers. WinRAR test, store the WinRAR archive, WinRAR extract a working tree. WinRAR split volumes catalogued together. WinRAR zip when the SIP specifies zip.
